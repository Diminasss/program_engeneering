# Анализ демографической статистики

Настольное приложение на PyQt5 загружает демографические данные из Excel, показывает их в таблицах и строит графики фактических значений вместе с прогнозом. В интерфейсе доступны две вкладки: доля детей, рождённых вне брака, и численность населения России.

## Возможности

- чтение исходных таблиц `tables/children.xlsx` и `tables/population.xlsx`;
- сортировка и отображение данных по годам;
- расчёт максимального относительного роста и снижения показателя;
- построение графика средствами Matplotlib;
- выбор горизонта прогноза от 1 до 20 лет;
- прогноз методом скользящей средней с окном в 15 наблюдений.

## Технологии

- Python;
- PyQt5;
- pandas и NumPy;
- Matplotlib;
- openpyxl.

## Установка и запуск

Перейдите в каталог работы:

```powershell
cd "By order"
```

Создайте и активируйте виртуальное окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Установите зависимости и запустите приложение:

```powershell
pip install -r requirements.txt
python main.py
```

Приложение также собрано в `main.exe`. Его следует запускать из каталога `By order`, чтобы относительные пути к Excel-файлам разрешались корректно.

## Использование

1. Откройте нужную вкладку.
2. Укажите количество лет прогноза.
3. Нажмите **«Собрать статистику»**.
4. Просмотрите таблицу, максимальное изменение показателя и график с прогнозом.

Фактические значения показаны сплошной линией, прогнозные — красной пунктирной. Каждое следующее прогнозное значение вычисляется по последним 15 значениям движущегося окна.

## Структура

```text
By order/
├── main.py             # главное окно и вкладки
├── children.py         # статистика детей, рождённых вне брака
├── population.py       # статистика численности населения
├── tables/
│   ├── children.xlsx
│   └── population.xlsx
├── requirements.txt
├── main.spec           # конфигурация сборки PyInstaller
└── main.exe            # готовая сборка для Windows
```
