# Лабораторная работа №3 — графовая база данных Neo4j

Работа демонстрирует моделирование предметных областей в Neo4j, выполнение запросов на Cypher и визуализацию результатов с помощью NetworkX и Matplotlib. В каталоге находятся два варианта графа: учебный интернет-магазин и железнодорожная станция.

## Реализованные варианты

### Интернет-магазин — `Exersise.py`

Скрипт создаёт пользователей, товары и связи-заказы `ORDER`, после чего выполняет запросы для поиска:

- пользователей, оформивших заказ;
- товаров без заказов;
- пользователей с несколькими заказами;
- общего количества заказов;
- максимальной стоимости сделки;
- лидеров по количеству заказов и сумме расходов.

### Железнодорожная станция — `my_variant.py`

Вариант описывает работников, отделы, бригады, администрацию, локомотивы, маршруты, пассажиров и билеты. Cypher-запросы извлекают сведения о водителях, маршрутах, диспетчерах, ремонтных работах, медицинских осмотрах, составе отделов и проданных билетах.

## Технологии

- Python;

- NetworkX;
- Matplotlib;
- python-dotenv.

## Подготовка окружения

Для работы нужен запущенный Neo4j с учётной записью, которая может создавать и удалять базы данных. Создайте виртуальное окружение и установите зависимости:

```powershell
cd Lab3
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Создайте файл `.env` со своими параметрами подключения:

```dotenv
NEO4J_URI=neo4j://localhost:7687
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=your_password
NEO4J_DBNAME=shop
NEO4J_DBNAME_WITH_OPTION=railway
```

Файл `.env` добавлен в `.gitignore`; пароли и другие секреты не следует сохранять в репозитории.

## Запуск

Интернет-магазин:

```powershell
python Exersise.py
```

Железнодорожная станция:

```powershell
python my_variant.py
```

Оба скрипта при запуске удаляют базу с заданным именем, создают её заново и заполняют тестовыми данными. Используйте отдельные учебные базы, в которых нет нужных данных. Результаты запросов выводятся в консоль, а изображения сохраняются в `pictures/` и `variant_pics/`.
